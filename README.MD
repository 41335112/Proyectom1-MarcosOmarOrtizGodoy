# AGENCIA COLORFLY STUDIO

Colorfly Studio es una agencia de branding que produce propuestas visuales. Esta aplicacion permite generar diferentes combinaciones de colores de manera aleatoria y visualizar en una interfaz sencilla y agredable.
Este proyecto esta pensado para facilitar la creacion de paletas de colores para diseños, paginas web y proyectos a futuros.

## Caracterizticas de la aplicacion

- Generacion aleatoria de paletas de colores.
- Seleccionar la cantidad de colores (6-8-9).
- Seleccionar el formato de colores: "hsl/hex/rgba".
- Visualizacion de colores mediantes bloques.
- Opcion para guardar paleta.
- Opcion para eliminar paleta.

## Tecnologias utilizadas

- HTML --> Es la estructura de la pagina web.
- CCS --> Estilo y diseño visual.
- javaScrip --> Es la parte de la logica (generacion de colores y funciones de la aplicacion).
- Git/GitHub --> Git-->(seguimiento local) GitHub-->(seguimiento y repositorio en la nube).
- GitHub Pages --> Publica el proyecto web en la internet usando el repositorio.

## Utilizacion de la aplicacion

1. Ingresar a la pagina web.
2. Seleccionar la cantidad de colores (6-8-9).
3. Seleccionar el formato de los colores (hsl/hex/rgba).
4. Seleccionar el boton generar paleta de colores.
5. Visualizar los colores aleatorios.
6. Guardar paleta de colores.
7. Eliminar paletas de colores.
