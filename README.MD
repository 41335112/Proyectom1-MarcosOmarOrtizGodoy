# AGENCIA COLORFLY STUDIO

Colorfly Studio es una agencia de branding que produce propuestas visuales. Esta aplicacion permite generar diferentes combinaciones de colores de manera aleatoria y visualizar en una interfaz sencilla y agredable.
Este proyecto esta pensado para facilitar la creacion de paletas de colores para diseños, paginas web y proyectos a futuros.

👉 [Visitar Colorfly Studio](https://41335112.github.io/Proyectom1-MarcosOmarOrtizGodoy/)

## 1. Caracterizticas de la aplicacion

- Generacion aleatoria de paletas de colores.
- Seleccionar la cantidad de colores:
     - 6.
     - 8.
     - 9.
- Seleccionar el formato de colores: 
     - hsl.
     - hex.
     - rgba.
- Generar paletas de colores.
- Visualizacion de colores mediantes bloques.

## 2. Tecnologias utilizadas

- HTML --> Es la estructura de la pagina web.
- CCS --> Estilo y diseño visual.
- javaScrip --> Es la parte de la logica (generacion de colores y funciones de la aplicacion).
- Git/GitHub --> Git-->(seguimiento local) GitHub-->(seguimiento y repositorio en la nube).
- GitHub Pages --> Publica el proyecto web en la internet usando el repositorio.

## 4. Utilizacion de la aplicacion

1. Ingresar a la pagina web.
2. Seleccionar la cantidad de colores (6-8-9).
3. Seleccionar el formato de los colores (hsl-hex-rgba).
4. Seleccionar el boton generar paleta de colores.
5. Visualizar los colores aleatorios.
 
## 5. Desiciones tecnicas 
1. **HTML :** Se utilizo html5 para organizar los diferentes elementos de la aplicacion, como:

 - Titulo.
 - Opciones para la cantidad de colores.
 - Seleccionar algun formato.
 - botones (generar paleta de colores).
 
2. **CSS :** Se utilizo para darle estilos a la aplicacion y pueda adaptarce a diferentes tamaños de pantallas.

3. **JAVASCRIPT :** JavaScript se utilizo para darle logica y funcionamiento a la pagina.

   Podemos identificar las funciones principales:
   - Generar colores hsl.
   - Generar colores hex.
   - Generar colores rgba.
   - Generar paletas de colores.
   - Visualizar paletas de colores.

4. **GITHUB PAGES :** La aplicacion se publicara utilizando GitHub Pages, para eso necesitamos seguir estos pasos:
   1. Crear un repositorio en GitHub.
   2. Subir los archivos del proyecto.
   3. Ir a configuracion o Settings.
   4. Entrar en Pages.
   5. Seleccionar la rama donde se encuentra el proyecto, rama main.
   6. Seleccionar la carpeta /root.
   7. Guardar los cambios.
   8. GitHub Pages, va a generar un enlase para que se pueda acceder a la pagina web.
